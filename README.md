# PhysicsTracker

PhysicsTracker is an offline Android video motion analysis app for classroom physics. It is built with Flutter and uses the Android/Kotlin host project generated by Flutter.

The app helps teachers and students import or record local videos, move frame by frame, manually track object positions, generate kinematics data, plot graphs, and export analysis results.

## Features

- Local video project creation
- Frame-by-frame video analysis
- Manual point tracking on the video frame
- Tracked-path overlay
- Data table for position, velocity, acceleration, momentum, kinetic energy, and force
- Interactive motion graphs
- Curve fitting: linear, quadratic, sinusoidal, and exponential
- Calibration math support
- CSV and annotated PNG export services
- In-app recording screen
- Line intensity profiling screen
- Fully offline local storage

## Tech Stack

- Flutter and Dart
- Android host project with Kotlin `MainActivity`
- Riverpod
- Hive local persistence
- Freezed model generation
- FFmpeg Kit for metadata and frame extraction
- `video_player`
- `fl_chart`
- `camera`
- `image`
- `path_provider`
- `share_plus`

## Getting Started

Install Flutter, then run:

```bash
flutter pub get
flutter test
flutter run
```

For code generation after model/provider changes:

```bash
dart run build_runner build --delete-conflicting-outputs
```

## Current Status

This repository is a standalone clean copy of the PhysicsTracker app source. It excludes papers, side projects, generated build output, APK files, logs, and BMAD planning artifacts.

The app is currently a research prototype and should be validated before Play Store release.

## Privacy

PhysicsTracker is designed to run offline. It does not require user accounts, Firebase, analytics, ads, or runtime network calls.
